# 什么是 CHIP-8？

CHIP-8 是一种运行在 CHIP-8 虚拟机上的解释型编程语言。它是一个相当简单的系统，可以
运行 PONG 和 Space Invaders 这样的游戏。

# 为什么选择 CHIP-8？

CHIP-8 看起来像是模拟器世界里的 Hello World!。它是一个相当简单的系统，只有单色图形和
一种声音。它有 16 个 8 bit 寄存器、16 bit 程序计数器、8 bit 延迟计时器、8 bit 声音计时器和 4k 内存。
如果你想为 CHIP-8 写一个模拟器，我强烈推荐下面这份[手册](http://devernay.free.fr/hacks/chip8/C8TECH10.HTM#1nnn)
以及 Wikipedia 的[文章](https://en.wikipedia.org/wiki/CHIP-8)。

如果你想获得更多帮助，也可以看一眼这篇[文章](http://multigesture.net/articles/how-to-write-an-emulator-chip-8-interpreter/)。

# 我该怎么做？

chip-8 大致就是这样工作的。

```go

func emulateCycle() {
  // fetch opcode
  // decode opcode
  // execute opcode
}

func Run() {
  for true {
    emulateCycle()
    
    renderGraphics()
    
    handleKeyPress()
  }
}
```

为了让 CPU 工作，你需要实现大约 35 条指令，不过现代解释器只需要其中 34 条。

# 你用什么写了这个模拟器？

![Golang](https://ih0.redbubble.net/image.377846317.0222/flat,900x900,070,f.jpg)

我用 Go 写了这个模拟器，主要是因为我想学习这门语言。我没有使用任何与并发相关的
特性，比如 channels 或 goroutines。使用 Golang 让我能有意识地关注我创建的每个寄存器的大小，
因为 Golang 不支持隐式类型转换。我喜欢这门语言的另一个特性是它开箱即用的
测试支持。

我和一位朋友聊过，他指出了一些提升 Golang 能力的资源。

- [Go Lang 代码审查评论](https://github.com/golang/go/wiki/CodeReviewComments)
- [Effective Go](https://golang.org/doc/effective_go.html)

我还没有找到时间读这些，希望很快能读。

更新：图形/键盘/声音方面，我正在使用一个叫 [Ebiten](https://github.com/hajimehoshi/ebiten) 的库。我刚收到这个库作者的一个 pull request，帮助提升模拟器的性能。
