我本以为不会写这篇，但我刚刚看到 [@shubh24](http://shubhankar.xyz) 写了一篇很棒的文章。

和他的文章不同，这篇没有回顾。如果你想看回顾，读我的博客。看我的视频。翻翻我的 GitHub。

这篇文章说的是那些没有完成的事。写这篇文章的灵感来自我姐姐把我在浦那陆军公立学校担任学生会主席时发表的最后演讲交给我。你可以在[这里](/files/speech.pdf)找到那篇演讲。

演讲中很大一部分来自 Steve Jobs、Rocky Balboa、Any Given Sunday、孔子以及其他人。何必重新发明轮子呢，对吧？

所以我最近去了克久拉霍，路上在占西停了一下。在某个人办公室前面，我看到了这个。

![平庸](/img/blog/mediocrity.jpg)

这概括了我对 2017 年的计划。我正在努力摆脱通往平庸的道路，走上通往卓越的道路。正如 Gary V 在他的[视频](https://www.youtube.com/watch?v=RBXZlYdiizk)里说的，22 岁是任何人一生中最棒的年纪。

我的演讲在无意中成了那种写给未来 X 年后自己的信。大学把现实带了进来，梦想变成了梦想。我不能让这种状态继续下去，不能辜负 4 年前写下那篇演讲的那个男孩。

不要将就，多做一点，是 2017 年的信条。我列出了一些我计划在 2017 年定期做的事。

- 做
    + 不喝汽水
    + 定期视频日志
    + 每天跑步
    + 做出美好的东西（一个产品）
    + 基于我在新加坡科技设计大学期间经历的研究论文
    + 在开放麦上表演单口喜剧
- 学习
    + 掌握 Web 安全
    + 全栈开发
    + 口琴
    + 半程马拉松
    + 烹饪
    + 函数式编程
- 旅行
    + 巴厘岛

关于做出美好的东西，如果你是前端开发者，想参与一个项目（或很多项目），请给我[发邮件](mailto:anomaly.the@gmail.com)。我能把后端跑起来，但有些项目一直无法落地，因为我的 CSS 和前端技能太糟糕。

我之前列过一个叫 Goals 的清单。同样，我不会提已经完成的，而会提没有完成的。我一直想做漏洞赏金计划。2017 年我计划开始做 Bug Bounties，并把它做得不错。这和我对 Web 安全的热爱以及远程生活和工作的目标相契合。我原以为到上学期结束时会和 [@psdh](https://psdh.github.io) 以及 [@shubh24](http://shubhankar.xyz) 做出一个有不错用户基础的产品，但那没有发生。看看什么时候会发生吧，不急。

来吧，2017。来吧，生活。
